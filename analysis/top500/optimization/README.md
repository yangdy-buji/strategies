## 特别需要注意

- 日期过滤修复会恢复原默认日期，包括SID4621的2020年窗口，不能与原来忽略日期的十年结果直接比较。
- SID3322保留100%止损默认（对应零价格），本次只修保护提交时机；首次保护仍须等成交后的计算机会，不能当作充分风险控制。
- SID4143/4941保留多层仓位和零数量反向entry退出原行为；加撤单并不代表这些策略已可实盘。
- SID735仍保留原bull_cross退出门禁；SID5369从使用中轨转为正确上轨会改变信号数量，不保证收益增加。
- SID3883因alertcondition消息要求常量，改为查看实际Buy Amount参数的提示；没有修改真实下单金额、加仓上限或报警通道。
- 卡片分别列出“本轮处理”“仍需关注”和“原版审查上下文”，避免把已经修复的问题当作仍然存在；源码差异是修改范围的最终依据。

## 重建与检查

在当前worktree根目录执行：

```sh
python3 -m unittest discover -s tests
python3 -m tools.strategy_optimization.build
python3 -m tools.strategy_optimization.verify
node tests/test_optimization_ui.cjs
```

输入为既有`analysis/catalog.json`和`analysis/top500/ranking.json`。所有原策略先校验SHA256；补丁还绑定提取代码SHA256和唯一匹配片段，漂移则拒绝写出。生成器不执行策略、不访问券商、不运行外部回测程序。

如果先重建原排名页面，再运行优化构建器，才能恢复卡片上的优化链接。优化构建器不会修改原排名JSON、CSV或其评分。

后续性能比较需要同股票池、同日期、同成本及同仓位逐笔对照原/新版，并使用独立后续窗口。本轮未部署；本地合并与推送状态见[验证记录](validation.md)。用户约定的部署验证门禁未完成，不能自动推送。
