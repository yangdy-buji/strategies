# 表现与逻辑融合研究排名方法 v1

## 这份名单回答什么

在用户提供的既有回测范围内，按统一且可复算的规则安排策略研究顺序。不是全库所有策略都完成同口径回测，也不是500个已验证可实盘的策略。

严格日线主榜与小股票池初筛补充候选分开。主榜有独立名次，补充候选仅有研究名单序号及其初筛池内名次，不能拿补充候选分数/收益直接与主榜比较。

## 数据来源与身份

输入来自用户指定的 `量化回测结果_2026-10-20` 本地目录，按白名单读取CSV、JSON/JSONL。没有读取凭证，没有执行来源目录脚本，没有重新回测。

主键以 `all_scored.csv` 的 sid → repo_path basename → 本地 filename 精确匹配。`features.jsonl` 中的规范化MD5与当前提取源码匹配；该算法删除注释、替换全部字符串、压缩空白并小写，所以是**有损内容一致性证据，不是严格版本绑定**。原回测仓库快照及strats.json未提供。每张卡片另绑定本地原文件SHA256；每个实际读取的输入文件另记录SHA256和行来源。

## 主榜与补充准入

1. 主榜合并 `all_results.csv` 中 full_universe 与 `all_552_daily.csv` 的成功重跑；同sid优先552重跑。
2. 查原始stage2/daily500记录，包含stage2_reused映射；主榜要求错误数明确为0、运行股票数不少于1000、交易数不少于100、组合平均资金暴露不少于2%。个别股票报错的结果单列排除，不把剩余股票结果当完整无错误测试。
3. CAGR、Sharpe、Calmar、最大回撤须为有限值，回撤在[-100%,0]；缺失不是0。
4. 排除已标记成交假象、日线Sharpe>3、旧综合榜异常标记，以及本地已保存任何周期Sharpe>3的结果。Sharpe阈值只是保守研究门槛，不能证明阈值内结果没有成交偏差，也不能证明阈值外必然作弊。
5. 按历史代表组固定选已有回测的代表，否则选最低sid；先固定代表，再检查质量，不能因代表结果差就挑表现好的副本。此分组是源目录提供的去重分组，可能包含近似策略；不同源码即使指标相同也不自动视为同一策略。
6. 补充池仅使用未有全市场记录组的50股票初筛，独立计算分布。初筛实际运行股票数字段缺失，保持未知，不补50。补充不重新引入已因异常或报错隔离的全市场组；全量运行失败、超时、缺少收益字段的尝试及其近重复也禁止回流。编译/不支持语法等运行前预筛跳过可保留初筛证据，但逐项展示原因。

“严格”指本版数据准入门槛，不表示引擎已忠实模拟原策略。

## 评分公式

分别在主榜完整候选池、初筛完整候选池中计算，不能在选出的49个补充项中重新计算百分位。

```
日线表现分 = 100 × [0.30 × pct(Sharpe)
                    + 0.25 × pct(Calmar)
                    + 0.25 × pct(CAGR)
                    + 0.20 × pct(MaxDD)]
近三年历史分段分 = 在同一证据层内，用末3年指标按同样公式计算
综合研究分 = 0.70 × 日线表现分
           + 0.10 × 近三年历史分段分
           + 0.20 × 已有逻辑合理性分
           - 静态风险扣分
```

百分位取平均并列名次，线性缩放到0—100；回撤为负数，越接近0越高。单项样本只有1个时为50。缺少历史末段指标，该项不获分并明确提示最高损失10分，**不是把缺失收益视为0**。

已有逻辑分使用上一轮目录分数及其复核状态，不将自动初评分伪装为专家评级。旧回测目录合理性分已含15%绩效，因此不再并入总分，避免重复计入表现。

静态前视疑点扣15分，静态实现疑点扣10分，最多扣25分。依据来源features和red_flags展示；静态标记不等于已确认作弊/运行错误。新一轮精读发现另外的问题在卡片与风险列显著列示，**不因只精读部分策略就对这些策略单独改写原逻辑分**。因此数值排名仍须结合重要疑点阅读，不能把第一名当作最可执行的策略。

以上权重是预先固定的研究偏好，不是通过样本优化得到，也没有统计概率含义。另列偏绩效80/10/10、偏逻辑55/10/35两种权重在各自完整准入池中的名次，只衡量排序规则敏感性，不是交易参数稳健性。

## 回测口径及无法补造的信息

- 日线：2016-01-04至2026-10-16；当前Russell1000/IWB成分股回看历史，存在幸存者偏差；每策略实际成功股票数逐项显示。
- 资金/费用：报告初始100,000，单边0.1%；单股票固定单位信号，组合收益为Σ持仓收益/max(活跃数,20)。
- `exposure = mean(min(活跃股票数,20)/20)`，是**组合平均资金暴露**，不是每只股票持仓时间占比。至少20只股票同时持仓即可接近100%，不能仅据此说策略长期持有。
- `oos3_*` 是同一历史末756个日频观测，不是独立样本外。默认参数也不能消除筛选偏差。
- 日内：200只高流动性股，允许隔夜。5/10/15分钟约2年，30分钟/1小时约5年；不是天然日内平仓策略。
- 本地仅有1小时全榜、其余周期Top100及旧汇总。日内只作交叉证据；没有中性50填充，也不从Top100重算全榜百分位。重复1小时记录优先全榜，保留另一来源供核查。
- 没有原始逐日净值或逐笔交易序列，不能生成真实年度收益、回撤恢复期、交易集中度、收益相关矩阵或新权益曲线。不能把跨周期交易数相加当独立样本。

## 引擎保真限制

外部源码显示数量、部分平仓、加仓、部分strategy.risk风控、会话语义未完整执行。成功运行只是解释器跑完，不代表原始Pine策略保真。限价/止损单可能受OHLC路径假设影响；没有触发Sharpe>3规则仍可能高估。

卡片针对每项实际源码/特征列出差异，区分入场stop触发、持仓stop止损与limit限价，区分普通qty和加仓，不把参数声明当作已生效功能。当前卡片是研究分析，未完成逐笔原平台对照。

## 卡片深度与更新

全部入选策略有具体条件、参数、绩效解读和保真差异。自动语义辅助的复杂控制流仍待复核，不能称逐份完整源码审计；本轮精读的策略单独标识，重要发现列在首部。原始文件保持不变。

`reviews/` 是本轮源码精读记录，绑定本地SHA256。生成器与复核记录纳入分支；大体积生成HTML、卡片及JSON保留本地，可重建。外部回测输入不改写。
