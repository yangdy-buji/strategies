TOP300 Pine Script 独立文件包

检查结论：300项全部已经是Pine Script，因此跨语言转换数量为0。本包将原Markdown中的完整策略源码原样提取为300个.pine文件，不修改交易逻辑，不升级语言版本。
文件名格式：三位排名_SID策略编号_稳定ID.pine。排名来自本次TOP300研究名单。
manifest.csv / manifest.json记录策略中文名称、排名、版本、原始路径、原文件SHA256、提取文件SHA256及待核验事项。

本包统一使用原版源码，与历史回测研究名单保持来源一致。已存在的修复候选不混入本包；它们位于analysis/top500/optimization/variants，尚未重新回测。
原作者的backtest注释块原样保留，不表示本次执行过回测。5项未显式声明版本；2项有重复版本声明，均在manifest中标注。
原生Pine编译未执行。已验证300项身份唯一、原文件指纹、每个提取文件与原文源码逐字节一致、压缩包完整性；这不代表300个策略均能直接编译或已适合交易。
导入时根据manifest按SID找到文件，将完整文本粘贴到Pine编辑器，先检查原生编译结果；不要只修改版本号来升级旧版源码。
